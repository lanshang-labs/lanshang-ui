# Studio Workspace · 后台工作台实验

组合方式：TypeScript / React 18 + 现有 Ant Design 5.22.5 + 完整页面视觉。标准交互直接由 AntD 承担，业务样例状态放在页面，视觉使用局部主题和 CSS。没有新增共享组件、依赖或正式包导出。

## 视觉简报

- 产品：小型设计／产品团队的项目交付后台，主任务为看进展、找阻塞、更新项目。
- 主参考：[Dashboard Sidebar — Arun Dass](https://21st.dev/@arunjdass/components/dashboard-sidebar)，采用低对比分区、克制导航、侧栏与工作区的整体关系。
- 辅参考：[App Dashboard Layout — shadcnstore](https://21st.dev/@shadcnstore/components/app-1)，参考总览指标、交付趋势与团队活动的排列。
- 21st CLI 仅搜索元数据并查看预览截图；没有获取或复制作者组件源码、图像或字体，不消耗代码获取额度，也不调用 AI 生成。以上参考不代表已取得第三方源码再分发许可。
- 主调：暖灰白、森林绿、低饱和中性色；深色保留相同信息层级和色相。状态同时有文字与圆点，不用色彩代替含义。
- 页面：224px 主导航、62px 顶栏，主内容按标题、摘要、指标、趋势／动态、项目表排列。留白以 16／20／24px 为主，面板圆角 11px；避免渐变、玻璃和装饰性动效。
- 首选任务入口清楚保留文字；刷新、主题、通知、更多等熟悉操作使用图标与提示。

## 预览与边界

实验室 `#/labs/admin-workbench`；整页 `/workbench-lab.html`。复用现有 5177 Vite 服务，无需再起服务。独立 HTML 文档避免旧包全局 CSS 和根 Provider 影响新组合；仍是同一份 React / AntD 依赖，使用独立 ConfigProvider 和 prefixCls。

包含总览、项目、运行记录、成员、设置；支持查询／状态筛选、项目创建和校验、详情抽屉和完成、全局搜索、通知、设置与本地成员添加。操作均为内存样例，没有后端请求、真实邮件或任务执行。日期、运行记录和团队存储为固定展示数据；项目指标由当前项目派生，图表范围只影响趋势。

页尾状态控制可检查首次读取和刷新失败；刷新失败保留成功快照，明确重试才恢复。手机侧栏使用 AntD Drawer，宽表在自己的区域横向滚动；浅暗主题、Modal、表单、菜单、分页等使用 AntD 原生行为。

本实验不沿用旧“所有控件必须经 Lanshang 入口”的实现约束，不代表通用组件库已迁移或新模板已经正式采纳。
