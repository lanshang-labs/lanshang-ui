# Lanshang UI 展示站结构

展示站本身是 Lanshang UI 的消费者。它展示组件时必须保留真实键盘、禁用、浮层和主题行为；站点外壳优先使用组件包提供的控件，普通链接和标题继续使用原生语义元素。


## 表面与空间层级

Lanshang 使用轻拟物、柔和立体感：浅色灰底承托白色内容卡片，以底色差、留白和柔和阴影表达抬起的表面；细边缘只作辅助，不能用强描边代替层级。卡片保持静止，不因这一规则增加悬停跳动。暗色沿用对应的中性表面明度与轻微边缘，避免浓重投影。

- 工作区底座与结构分栏为平面；需要承托多张卡片时使用共享 `ls-surface-stage`。卡片使用 `BeautifulSurface` 或同一组 `--ls-surface-*` tokens，标题和正文属于同一表面，不额外画一块灰色标题框。
- 导航、树与菜单悬停为灰底；浅色选中为带轻微阴影的白面，暗色为中性灰面。选中项在悬停时仍保持原表面；蓝色轮廓只标记键盘焦点，不能当作持续选中装饰。
- 弹窗与菜单属于更高层表面；表单边界、表格数据线、结构分隔线与错误轮廓仍承担各自语义，不把每个单元格、嵌套分区或内联提示都做成悬浮卡片。
- `variant="section"` 明确表示无独立外框的内容分节；实验室各模板保留其独立视觉。消费者必须加载对应版本的共享样式，不在页面覆盖卡片强边框、选中底色或复制公共阴影。


## 当前设计方向

继续维护现有 Lanshang UI，以一致性优化为主线，保留现有 AntD 底座、组件 API、主题与特色组件。实验室和已有对照方案继续保留；HeroUI、coss 或其他框架不作为默认替换目标。整体边界见 [架构说明](../doc/architecture.md)。

一致性优先覆盖同语义控件的尺寸、圆角、字体、间距、布局边界、表面层级、悬停与选中、键盘焦点、禁用与加载，以及浅暗主题和窄屏表现。继续遵循视觉优先：图标足以表达的常见操作采用图标并保留可访问名称和提示；对象不清晰、保存或危险确认等需要明确语义的操作保留文字。

从真实页面的问题入手，先修共享 tokens、主题适配或所属组件，再让相关页面复用结果；页面 CSS 负责布局，不为相同控件另设一套补丁。同轮修正按影响核对浅暗主题、窄屏及实际交互，保留已有 API、草稿、选择和焦点行为。

21st.dev 用于寻找组件、布局、动效和模板参考；吸收与现有规则协调且来源许可明确的部分。实验样例用于比较和验证，不自动修改默认主题或触发全库迁移。0.2.12 沿此方向发布一致性优化；实验室保留。

## 信息架构

- 顶部只区分文档、规范、组件和区块。
- 左侧按开始使用、设计规范、输入与操作、布局与展示、反馈与状态、组合区块排列；同一时刻只展开一个组，进入页面时自动打开所属组，搜索匹配项直接可见。搜索结果页保留筛选；后续导航到不匹配的页面时清除筛选，让当前页重新出现在目录中。
- 左侧顺序、面包屑和上一篇／下一篇共用 `navigation.ts`。新增页面必须加入该文件，并由 `docs-navigation.test.ts` 检查覆盖。
- 单页顺序为标题与摘要、可操作预览、接入方式、使用方式、可选配套源码、交互与边界、可选 Agent 接入要点、API。没有内容的段落不显示。预览区只放可操作示例；配套 CSS 和辅助文件放在独立源码段落，保留完整复制能力。
- 桌面预览区保留统一的最小展示高度；760px 及以下根据示例内容自然增高，避免简单控件在窄屏出现大块空白。长表格、代码与浮层仍由各自组件负责滚动和边界。
- 页内目录只在宽度至少 1320px 时并排显示；较窄桌面宽度保留单栏正文，避免断点附近预览区突然大幅变窄。
- 同一演示覆盖相邻控件页时，当前页的控件先出现，同时保留关联示例。日期选择先展示单日有效期，日期范围先展示筛选范围；滑动调节先展示独立滑块，再展示与精确输入共享数值的组合。
- “预览／代码”优先展示与该页对应的简洁使用示例；完整示例源码另提供下载，必要的辅助文件放在“配套源码”。“使用方式”“配套源码”和“复制页面”统一展示公开包入口；复制页面包含可见的安装说明、当前示例、必需的本地辅助文件及 API 信息，不能把展示站内部的 `../dist` 或 `../src` 路径交给使用者。

## 控件与自举

- 后台工作台实验 `labs/admin-workbench` 允许直接组合 React + Ant Design 与独立视觉参考，优先验收整页任务和状态；不要求使用旧组件包封装。原型通过同端口独立文档隔离主题和全局样式，保留来源与视觉简报，不修改正式包 API。

- 实验室通过独立 `labs/` 路由和导航分组展示未采纳的未来特性，按需加载。原型源码放在 `experiments/`，保留来源与原文；展示页的外围控件仍复用包入口。实验原型的专属物件交互可在该目录自包含实现，不据此建立通用按钮、主题或业务行为的第二套规范。实验不进入正式 `src` 导出、Registry 或包版本；正式采纳前单独核实来源许可、API、性能与交互合同。

- 默认尺寸为中号（32px 控件高）；小号只用于表格行内、API 文档等明确的高密度区域，大号用于宽松操作区。共享字段、按钮、`InputGroup`、`ButtonGroup`、`NumberStepper`、`RadioGroup` 与 `TabStrip` 继承最近的 `ConfigProvider.componentSize`，没有 Provider 时回退到中号，控件显式 `size` 优先；组合控件的尺寸须同时作用于外框与内部字段或选项，避免错位。开关只有小号与标准号，非小号使用标准号轮廓。
- 全局 Ant Design 默认圆角与骨架占位块沿用中号 10px；小号 8px、大号 12px 由控件尺寸显式切换，页面不能另设默认圆角来代替尺寸 token。
- 展示站目录、页内目录、工作空间侧栏、资源树与纵向页签的导航行均使用中号 32px 高度及中号圆角；纵向页签显式设置 small 或 large 时随尺寸 token 调整行高与圆角。密集表格的单元格按钮、展开按钮和行内编辑字段显式使用小号；任务队列行操作、工具栏与表格外的详情操作保持中号，并在窄屏换行，不通过压缩通用导航行来模拟密度。`DataTable` 分页属于表格底部的密集操作：默认 small，页码与前后页点击区 26px，当前页使用中性圆形底色，其他页透明，不叠加卡片阴影；条数选择器和跳页输入同步使用小号。底部上下留白 6px，窄屏自然换行；调用方显式设置 `pagination.size="default"` 可保留中号分页，独立 Pagination 的全局默认尺寸不变。
- 展示站与实时示例的控件从 `@lanshang-labs/ui` 使用共享入口；站点 CSS 只决定布局和阅读层次。表单、菜单、日历、表格和浮层等复杂交互由包内适配 Ant Design，保留其受控值、键盘、焦点、表单绑定及 Portal 行为。
- 中文展示站通过共享入口 `zhCNLocale` 配置根 `LanshangProvider`，使分页、确认浮层等默认交互文案保持中文；`DataTable` 的表头选择框额外以 `locale.selectAll` 命名（没有字符串时回退“选择全部”），保留原选择行为和调用方 `rowSelection.columnTitle`。单个组件仍可覆盖自己的 `locale`。
- 规范参数和接入约定中的静态表格也使用共享 `DataTable`，关闭分页并为窄屏提供横向滚动；页面不再手写表格边框、单元格留白和标题色。
- `DataTable` 的默认排序、筛选、分页跳页图标，以及显式启用的每页条数选择器箭头使用共享线条风格；默认筛选入口提供“筛选＋列名”的辅助技术名称。调用方的 `sortIcon`、`filterIcon`、`itemRender` 和 `showSizeChanger.suffixIcon` 继续生效。`TabStrip` 的溢出菜单也使用共享默认图标，显式 `moreIcon` 可覆盖；图标只表达操作状态，排序和筛选行为仍由表格管理。
- 表格行选择沿用共享 `DataTable` 的选中与跨页逻辑；展示实例通过 `rowSelection.getCheckboxProps` 给每行复选框提供包含记录名的 `aria-label`，使键盘和辅助技术能辨认当前记录。
- 展示站的装饰图标也经由共享 `@lanshang-labs/ui/icons` 入口使用 Iconoir；页面不直接导入上游图标包，交互动效图标仍使用 `MotionIcon` 或 `MotionButton`。
- 原生 `<a>` 用于导航；包括移动目录遮罩在内的按钮统一使用共享控件，不在展示页复制视觉状态机。
- `tests/site-self-hosting.test.ts` 检查展示站与实时示例的包入口、上游控件导入、原生表单控件和展示代码的 TSX 语法。
- 导航列表项和资源树使用共享 item 状态：浅色悬停为灰底，选中为带轻微阴影的白色块；深色悬停为深灰，选中为稍亮的中性灰，不叠加投影。表格行保留中性选中底色；不添加蓝色选中竖线，蓝色轮廓留给键盘焦点。悬停不能盖掉已有选中状态，强制颜色模式保留系统标记。
- 复选框视觉尺寸为 16px、圆角 5px，原生输入命中区至少 24px；浅色选中保持黑色，深色使用浅色中性标记。全选、半选、禁用和表单绑定沿用共享原生行为。
- 导航、标签、分段、单选和按钮组的滑动选中片共用表面阴影 token；浅色保持轻微层次，暗色不叠加投影，减少动态效果时取消位移动画。
- 工具栏设置入口使用共享 `MotionButton` 图标动效；固定和排序等状态操作使用共享行内按钮，并随控件尺寸缩放图标。业务状态仍由工具栏自身控制，图标播放不代表操作成功。
- 需保留焦点与说明入口的不可用操作使用 `aria-disabled`，由共享按钮样式统一显示弱化状态；调用方仍需阻止实际操作，加载中的主按钮保留忙碌反馈。
- `TextInput`、`TextArea`、`SearchField`、`Select`、`DateField` 和 `DateRangeField` 的默认清空入口使用同一个共享关闭图标，并随字段尺寸缩放；显式传入的自定义清空图标继续生效。`Select` 的多选标签移除图标也沿用该图形，保留原生移除和清空行为。`SearchField` 的输入框、内嵌搜索按钮和图标继承同一尺寸；放大镜只在点击提交时播放共享搜索动效，输入、回车和清空仍按原有语义调用。
- `DateField` 与 `DateRangeField` 的默认日历图标和范围分隔箭头使用共享 Iconoir 图形，并随尺寸缩放；调用方的 `suffixIcon` 与 `separator` 可覆盖默认值，不改变日期解析和键盘行为。
- `Alert` 的四种默认状态图标使用同一套 Iconoir 线条，关闭入口使用中号 32px 点击区和共享关闭图标；显式 `icon`、`closeIcon`、`closeText` 和 `closable.closeIcon` 继续生效，关闭回调与提示公告语义保持不变。
- `ConfirmPopover` 默认使用中性的共享警示图标；调用方传入 `icon={null}` 可隐藏，传入自定义 `icon` 可覆盖。窄屏时确认卡片固定在视口底部并限制高度，避免被表格滚动区裁切；确认、取消、Portal 与焦点行为继续沿用原控件。
- `CategoryTag` 与 `StatusTag` 可关闭时使用共享关闭图标，保留 `onClose` 取消关闭及调用方的 `closeIcon` / `closable.closeIcon` 覆盖；不可关闭的标签不增加多余操作入口。
- 标准下拉菜单与选择器浮层使用同一套中号卡片圆角、选项行高、留白和字体；已选标记、悬停探索和键盘焦点各自保持独立语义。
- 数字输入与滑块、生成表单复用 `NumberStepper` 的减号—输入—加号外框；步进动作、精确输入与滑块共用一个受控值，禁用与边界状态不改写为空值或代替表单校验。
- 浅色、暗色、窄屏和减少动态效果是每批页面调整的共同验收面。
- 正文、次要说明、弱提示及成功／警告／错误文字在 `canvas`、`surface`、`raised`、`selected` 中性底色上均保持至少 4.5:1 对比度；状态文字在各自浅色底上也满足这一阈值。禁用态另用禁用语义，不靠降低普通说明文字的可读性表达层级。
- `accent` 用于焦点轮廓和小型状态图形，`link-text` 用于可阅读的链接、信息标题与代码关键字；浅色主题不得直接把强调蓝作为小字号文字色。
- 代码示例的关键字、字符串、函数与数字使用共享语法色 token；浅暗主题均对代码卡片表面保持小字号文字对比度，示例页不单独覆盖高亮色。
- 清楚、常见且可区分的紧凑工具栏操作优先用语义图标，不重复排列图标和文字；仍保留中号命中区、可访问名称、悬停提示与键盘焦点。持续状态使用 `aria-pressed` / `aria-expanded`，结果用文字反馈；含糊、危险或需要明确对象的操作继续配文字和必要确认。
- 页面复制、输入组合中的刷新、搜索和清空属于上述图标优先操作；按钮不再重复显示同义文字。对齐方式等缺少明确图形的选项保留文字，不能把所有按钮机械替换成图标。
- 固定布局优先用 `--ui-shell-sidebar` 的轻微灰底与 `--ui-shell-canvas` 正文形成分区，`--ui-shell-line` 只作轻细分隔，不能靠加深黑线表达结构。文档目录、全局侧栏、树面板、分隔面板和 Studio 样板共用此规则，移动目录的搜索底色也随侧栏。暗色保持原有底色与分界；表格行线、卡片内部细分仍使用 `--ui-line`。
- `SourceCodeBlock` 的换行与复制使用中号共享动效图标按钮；换行的折返箭头在每次切换时短暂移动，`aria-pressed` 表示当前状态，减少动态效果时直接显示结果。复制成功或失败只由剪贴板结果决定，箭头跟随菜单开合。代码卡片的局部样式不手绘另一套操作图标。
- 兼容 `CodeBlock` 的复制入口也使用中号共享按钮，保留调用方文案、成功对号与失败说明；示例页以 `SourceCodeBlock` 为主要接入入口。
- 选择器、菜单、日期面板和通知托盘共用浮层阴影变量；浅色保留轻微投影，暗色以表面色与边界建立层次，不叠加黑色拟物阴影。
- 示例卡片、资源树外框、分隔面板与 Studio 样板共用表面色、边界和阴影 token；浅色仅保留轻微层次，暗色只用表面色与边界。嵌套面板不重复叠加阴影，示例容器不自行发明另一套材质。
- `DateField` 与 `DateRangeField` 的日历弹层随 small / middle / large 同步改变面板宽度、标题高度、内边距、日期格和字号；窄屏由视口宽度约束并按原顺序排列。三档视觉与输入尺寸同源，真实使用不需要复制示例 CSS。调用方的 `popupClassName` 与共享类名并存。
- `UploadControl.Dragger` 自带卡片表面、悬停与键盘焦点样式；页面只负责文件卡片、预览尺寸与长文本排版，不复制拖拽区外观。调用方的 `className` 与共享类名并存。
- `Skeleton` 只让默认的整块占位撑满容器；自定义 `template` 使用共享 `SkeletonAvatar` 和 `SkeletonBlock` 时，头像保持自身宽度，段落按布局占用剩余空间。减少动态效果对独立占位子组件同样生效。
- 对话框、抽屉、确认卡片与提示气泡的表面、圆角、文字层级和浮层阴影由共享 `Dialog`、`DrawerPanel`、`ConfirmPopover`、`HintTooltip` 管理；确认卡片内自行提供操作区时使用 `ConfirmPopover.hideDefaultActions`，示例 CSS 只处理弹层宽度、滚动与长文本换行。
- `Dialog` 与 `DrawerPanel` 的关闭按钮使用中号 32px 点击区和共享关闭图标，默认分别以“关闭模态框”“关闭抽屉”命名；调用方可用 `closeAriaLabel` 指定上下文名称。`closable`、自定义 `closeIcon`、关闭回调和原生焦点范围保持有效。
- 浮层卡片内的错误反馈使用共享 `FeedbackPanel variant="inline"`，由组件提供分隔线、文字层级与窄屏留白；页面只负责错误文案和恢复操作，不覆盖反馈面板内部样式。
- 站点壳在 760px 及以下切换为双行顶栏和抽屉目录；布局切换、侧栏隐藏与目录按钮显示使用同一断点，避免侧栏盖住正文。
- 窄屏目录通过 Escape 或遮罩关闭时，焦点返回“目录”按钮；选择页面后焦点进入正文，避免键盘路径回到文档开头。
- 打开窄屏目录时先聚焦目录容器，下一次 Tab 直接进入目录搜索；不让顶栏主题按钮插入目录键盘路径，也不自动弹出触屏键盘。
- 页内目录在 1320px 以下隐藏时，正文网格同步切为单列，不保留空的目录列。
- 同一断点内收紧顶栏间距与搜索宽度并隐藏版本徽标；示例区在 1050px 及以下缩小内边距，760px 及以下再随双行顶栏调整，避免只改目录而留下宽屏尺寸。
- 页内跳转的预览区与正文段落共用顶栏避让：桌面保留 88px、760px 及以下保留 120px；`#demo` 不沿用旧的固定 100px 偏移。
- 页内目录跳转后，焦点落在对应内容区域，键盘可从该处继续阅读；全宽示例保留独立的紧凑内边距，不被通用预览留白覆盖。
- Studio 风格样板保留独立的 `style-study.html` 入口，并随展示站一起构建；两个入口共用展示站主题偏好与 `zhCNLocale`，跨页切换不改变浅暗主题。侧栏导航使用中号行高，760px 及以下改为横向导航。项目名称用共享小号行内按钮打开对应详情，使窄屏不用滚到末列也能完成编辑；原末列操作保留。其局部 CSS 只设置页面装饰图标和排版，不统一覆盖共享控件内部的 SVG 尺寸。

自举按控件所有权推进：站点外壳和基准页、输入与操作、表格与资源展示、浮层与组合区块。展示站源码不直接导入 Ant Design；包内适配层保留上游交互语义，并提供 Lanshang 的默认尺寸、主题与交互样式。新增控件必须同时验证表单绑定、焦点、禁用、加载和关闭行为，不能只改导入路径。

单图卡片与叠卡共用 `ImageCard` 的纸片画框、内嵌标题和预览入口；单图默认自然比例，不把完整参考图放进固定灰色方块。备用图只重试一次，资源与原图预览由消费者持有。图片叠卡由共享 `ImageDeck` 提供，收起时最多显示四层，滚轮翻阅、键盘切换、点击展开与自适应布局属于组件；图片资源、原图预览和业务反馈属于消费者。展开与归拢使用同一组卡片的位移，不挂载另一套图库；浅暗主题不改变图片颜色，减少动态效果时直接呈现目标状态。组件默认沿用中号 32px 图标操作区，并为触屏保留翻页和展开入口。

Markdown 只负责源字符串的语义展示，使用 CommonMark、GFM 与可关闭的数学公式；正文默认继承中号，保留浅暗主题、紧凑表格和局部横向滚动。代码复用 SourceCodeBlock，图片复用 ImageCard，不重复实现工具栏与画框。任务项只读；原始 HTML 不执行，外部链接保留安全跳转，脚注按实例隔离且不抢占站点 hash 路由。业务提示词、编辑和审核状态不归渲染组件。

## 复杂工作台布局

`WorkspaceLayout` 管理可选全宽 topbar、sidebar + main 行、工作区 header 和全宽 footer。旧用法默认保持正文 padding 与独立滚动；嵌入 `WorkspacePanels` 时显式使用 `contentMode="panels"`，把滚动和留白交给栏目，避免两层正文滚动。

`WorkspacePanels` 使用平面的 start / main / end 栏目，不通过嵌套卡片制造分区；辅助栏使用 shell-sidebar，正文使用 shell-canvas，以柔和细线区分。每栏有固定头尾与独立可聚焦滚动区。像素宽度、折叠、窄屏活动栏和沉浸状态允许受控，回调只提议变化；当前实现不持久化偏好。

响应式以组件自身容器宽度和主区宽度预算为准。空间不足时展示具名面板切换，保留隐藏内容的实例、选择、草稿和滚动；隐藏栏不参与键盘导航。沉浸只展示主区，退出恢复既有宽度与收展。手柄支持拖拽、方向键、Shift 加速和 Home / End；隐藏当前焦点时转移至可见面板入口，不能把焦点留在隐藏区或抢走外部操作焦点。

全局布局页提供生产工作台和文档工作台。示例请求与保存只更新本地内存，文档草稿使用纯文本控件，不把布局或 Markdown 渲染器描述为富文本编辑器。保存仍保留文字；刷新、收展和沉浸使用图标及可访问名称/提示，多个面板入口保留标签以区分对象。

## 面向 Agent 的说明

普通“交互与边界”面向所有开发者；只有明确组件导入、状态职责和验收条件时才添加可复制的“Agent 接入要点”。不从一般说明自动拼出提示词，也不把复制成功当成组件功能已经接入。

Markdown 的列表标记属于组件，必须抵抗宿主菜单/列表 reset，保留 disc、decimal、嵌套层级与无额外标记的只读任务项。默认保留 CommonMark 软换行与链接导航；提示词通过显式 breaks 和 links="text" 选择换行保留及标签文字模式，不改源字符串。被安全过滤的空链接不得绘制可点击入口。

Markdown 默认提供共享页签的“视图 / 原文”切换和语义复制动效图标；原文只读、可选中，复制始终取完整输入字符串，保留换行和结尾空白，不从 DOM 或解析树重建。复制成功以真实剪贴板结果为准，失败保留手动复制入口。调用方可隐藏工具栏或受控切换模式，业务编辑和保存仍由消费者拥有。

图标优先也适用于列表行内编辑/查看、分页前后切换、侧栏收展和紧凑关闭入口；可访问名称保留操作对象，展开状态独立使用 aria-expanded，按钮沿用原焦点与禁用行为。保存、危险确认、状态演示切换，以及缺少清楚图形的操作继续用文字。

短图片/文件预览只保留顶部关闭图标，并用 closeAriaLabel 提供对应名称和提示，不再添加功能相同的底部纯叉号。长表单、嵌套核对等需要在底部结束流程的场景保留明确文字按钮；视觉优先不等于把所有退出动作都画成相同的叉号。

## 页面和区块加载

`LoadingContainer` 是页面／区块的统一等待容器。首次加载、刷新、失败和空结果使用同一套真实请求与成功快照语义：

- `hasContent` 显式表示已经取得成功结果，空结果同样为 true，不能用数组长度或 children 推断。
- 无成功内容时首次加载使用接近内容几何的 Skeleton（默认延迟 150ms 显示）或中性像素呼吸与文字流光；容器保留标题、操作与最低内容高度。
- 已有内容刷新与刷新失败保留同一内容 DOM、输入草稿和焦点，不加整页遮罩。刷新仅提示当前读取，不伪装成业务任务进度。
- 首次失败显示完整错误与重试；刷新失败明确说明仍显示上次成功内容。进行中的请求隐藏旧错误，结束、失败或取消后移除等待动效。
- 状态播报放在 aria-busy 内容区之外，骨架只作装饰；不重复播报。浅暗主题、390px 窄屏、长错误与减少动画均纳入验收。
- 页面与区块只改变布局层级，数据、取消、过期响应防护、空结果、权限、重试策略与焦点交接由消费者提供；不按时间自动把真实工作标记为成功。

## 统计与图表

- 统计展示分为无引擎依赖的 StatisticCard / RankingBarList / ChartCard，以及可选 @lanshang-labs/ui/charts 图表入口。仅图表消费者安装可选 peer @ant-design/plots；基础入口不导入图表模块。
- 看板组织参考 Tremor 的紧凑信息层级，Lanshang 自行实现表面、指标与排行；使用 AntV 作为单一图表引擎。已有表单、筛选、卡片与等待组件继续沿用。
- 浅暗图表主题显式映射 Lanshang 字体、文本、网格与分类色，不假设 AntD Provider 自动改变绘图。数据色与黑白控件主色分开：默认依次使用鸢尾蓝、青绿、暖金、紫、玫瑰与天蓝；主系列不再默认黑白。两种主题保持色相与系列顺序一致，暗色适度提高明度，避免白色数据压过其余系列。分类色不自动表示成功或失败，上涨不自动代表成功；保留图例、摘要与原始值，不能仅靠颜色传达信息。
- 同一次统计请求驱动多张卡片时，由父级 LoadingContainer 统一拥有加载、错误与恢复入口，子卡保留同一成功快照，不只给其中一张图提示失败。请求参数（包括请求空结果）与成功快照分开，失败不得用新参数清空旧结果；重试冻结原请求条件。
- 示例的累计数量按日截至当日，核对为完成子集；各日累计值不求和。指标、图例、原始数据与比较基准必须一致，固定7天比较不随7／14天观察窗口改变。
- 图表框架复用 LoadingContainer 的首次／刷新／失败语义。零、空结果和失败分开；聚合、时间口径、单位、格式、请求与重试由业务提供，不在组件中猜测。
- 普通图表提供语义名称、摘要和可展开原始数据表；数据表在展开后才渲染，键盘可独立滚动。像素色之外还应保留名称和真实值。迷你趋势的摘要需说明时间和含义。
- Tooltip、图例、轴和卡片留白保持紧凑。系统减少动态效果时关闭图表入场与更新动画；窄屏由容器自适应并让看板卡片换行。
- 面积图适合少量、含义明确的重叠序列；多层透明面积会混色，不能据此修改分类色或当作独立色块解读。多条临近或交叉序列优先使用折线、分面或交互筛选，并保留原始数据表。视觉审核应在入场与切换动画结束后判断颜色与线条。

## 基础视觉候选

实验室 `labs/foundation` 在现有 ShadcnStore 模板中对照 coss 中性视觉的 AntD 适配。32px 中号、浅暗中性主色、字段边界与轻微底阴影、16px 复选框、紧凑页签和小号分页保持同一规则。运行交互沿用 AntD，不据此安装第二套基础控件运行时。来源固定于 experiments/shadcn-dashboard/foundation-reference，保留目录级 MIT 声明和原始摘要。

候选与“现行主题 Tokens”仅在该独立文档比较；后者使用现有 designTheme，不代表已装载全部旧 CSS。样式切换保留草稿和当前内容。实验不修改默认 Provider、正式导出、发布包或原模板。该候选继续保留作参考，不作为全库迁移目标；后续若吸收其中的局部改进，先在现有 Lanshang 组件中验证按钮、字段、选择、表格和 Portal 的浅暗／窄屏行为。

## 第一轮一致性优化

本轮从 [21st 精选参考](../doc/design-references.md) 吸收局部视觉原则，继续使用现有 Lanshang 组件和 AntD 行为。保留小／中／大 26／32／38px、现有圆角、图标与动效，不将实验室候选替换为默认运行时。

- 主操作统一为中性实心：浅色使用深色填充与浅色文字，暗色使用浅色填充与深色文字；普通操作保持轻量。链接、键盘焦点与业务状态色独立，危险动作仍保留红色及确认语义。
- 普通字段与 InputGroup 共用控制边界 `--ls-control-edge` 和轻微阴影 `--ls-control-shadow`，与卡片／浮层边界分开；小号同样使用紧凑阴影，暗色保持无投影。聚焦、禁用、只读、错误和警告仍由对应控件表达，组合内部不重复描边。
- 分段与单选按钮的选中 token 同步为浅色白面、暗色灰面，保持原有滑动选中与键盘行为。
- Alert 采用 12px 共享浮层圆角、12px／14px 留白与无投影的内联表面，不再通过表面样式放大为 18px 圆角卡片；语义图标、文字与关闭操作保留。

验收使用现有按钮、输入、选择、组合控件、提示及浮层页面，并检查表单与表格组合场景；不新增另一套基础控件或替换实验室。当前仅本地构建与 5177 预览，未发布。

## 表格、表单与浮层的组合一致性

- 表格主体、内嵌详情和分页分工明确：展开区通过底色和缩进表示所属行，详情不再叠加卡片投影。直接返回已有框架的代码面板或子表时，不重复包裹外框。分页跳页字段沿用 small 的 26px 高、8px 圆角与共享控制边界；分页操作保持紧凑，横向溢出由表格内容区处理。
- Form 的多行输入字数统计独占一行，随后才是校验与说明，分组卡片无需另加计数补丁。长错误在所属字段内折行；FormGrid 继续拥有字段间距，校验不覆盖相邻字段。草稿、校验、提交与服务端错误仍由消费者负责。
- Dialog 与 DrawerPanel 统一拥有标题／正文／操作区的留白和细分隔线。长正文在自身区域滚动，标题和底部操作不随正文滚走；底部按钮按原顺序换行。页面无需再添加固定头尾或窄屏 padding 的重复布局规则。旧 ls-form-dialog／ls-form-drawer 样式类保持兼容，调用方显式样式与 footer=null 继续生效。
- 标题长文本折行并为关闭入口留位；短图片预览不补空操作区。选择器、菜单等 Portal 不挂入会裁切的滚动正文。嵌套层级、Escape、busy 守卫及关闭后焦点返回继续沿用组件和消费方的既有行为。

`patterns/overlay-recovery` 的“查看共享长表单弹窗”只使用包内默认 Dialog、FormGrid、Select 与 TextArea，不附加演示布局类；用于验证共享能力，而非再建一套弹窗模板。第二轮继续使用现有 5177，保留实验室，不发版。

## 导航、菜单、页签与树的一致性

- 当前项、展开分组和键盘焦点各自表达不同状态。展开不改变当前页面；悬停或移动焦点不替代选中，禁用项不获得可操作项的悬停高亮。树的活动节点使用独立 2px 内侧焦点框，只在树拥有焦点时显示；现有 AntD 方向键、展开和选择行为保留。
- 顶部和底部的普通内容页签使用同一紧凑轨道与滑动选中片。左右纵向页签保持列表形态，浅色当前项为白色轻阴影，暗色为中性灰；各行同侧对齐，不给后续行额外缩进。卡片页签继续保留与内容面板连接的形态，不机械改成胶囊。
- 折叠导航弹层与共享下拉菜单使用 32px 导航行、13px 字体和 10px 行圆角，外围采用共享浮层表面。无图标的导航子项不预留空图标缩进。菜单长名称可自然折行，不能越过视口。
- 页签溢出选择仍是原生 listbox，视觉密度与其他弹出导航对齐；不通过样式替换其键盘状态机。菜单的探索高亮、当前视图和内容页签保留各自语义。调用方的图标、禁用、选中、Portal 与事件回调保持。
- 普通资源树示例同时展示禁用项；长名称／六层嵌套与 220px 面板继续用于检查文字截断、完整提示、展开和选择保留。

第三轮检查使用现有导航交互页、分组导航、资源树和数据表格的真实溢出页签；继续在 5177 验证浅暗和 390px，保留实验室，不发版。

## 反馈、等待与恢复的一致性

- 行内提示保留紧凑中性表面和局部语义色；FeedbackPanel 与区块 LoadingContainer 使用共享 12px 圆角及较紧凑的留白。标题、说明与操作依次排列，错误不靠整块彩色背景表达。反馈标记统一为小面积色点或所属控件图标，不追加重复状态标签。
- 全局通知由托盘承担浮层阴影，内部通知保留边框但不再重复投影。长标题与连续标识在各自区域折行，关闭入口保留 32px 点击区；多条通知可以在托盘内滚动。关闭通知不代表业务问题已解决，也不清除原任务结果。
- ContentState 本身是 live feedback，loading 只决定外观，不自动在播报区域上设置 aria-busy；显式 aria-live／aria-busy 仍透传。忙碌数据区由调用方或 LoadingContainer 管理，LoadingContainer 的 pending status 继续放在 busy 内容区之外；不叠加多个相同加载播报。
- 首次等待与首次失败可以替换未成功内容；刷新及刷新失败保留成功快照、草稿和 DOM。空结果是一种成功结果，不因数组为空继续显示加载。计时、取消、幂等、未知结果核对和成功采纳仍由消费方拥有。
- 消费方若在重试后卸载原按钮，应在本次按钮拥有焦点、且焦点已落到 body 时转移到明确的结果／状态容器；用户已移动到其他区域时不抢焦点。忙碌期间用 MotionButton 的 aria-disabled 保留触发入口焦点及点击守卫，读取仍保留请求锁；逻辑不可用的入口继续使用 disabled。

第四轮以反馈面板、独立内容状态、LoadingContainer 的真实本地草稿链、通知与 Modal 协作以及 Alert 代表检查。所有请求均为本地演示；没有以文案“输入保留”替代实际草稿证据。继续使用现有 5177，保留实验室，不发版。


## 图片、文档、代码与统计展示的一致性

- 展示卡片使用共享 12px 面板圆角和中性细边界。ImageCard 与 ImageDeck 保留纸片构图和图片原色，画框内角为 8px；媒体独立入口的默认图标点击区同样为中号 32px。媒体专用 CSS 变量仍可覆盖默认值，不要求宿主加载全局 Provider 样式。
- Markdown 带工具栏时，“视图／原文”、复制入口与当前正文属于同一阅读框，工具栏下以细线区分正文，正文默认留白 16px、窄屏 12px。toolbar=false 仍为无外框的语义正文，供已有工作区组合；内嵌代码与图片不重复叠加投影。原始文本、只读语义、安全过滤和模式合同保持不变。
- SourceCodeBlock 使用 12px 面板圆角与紧凑工具栏，文件名可截断、代码长行在自身区域滚动或显式换行。复制与换行使用 32px 语义图标入口；兼容 CodeBlock 的复制同样图标优先，保留调用方名称、提示、真实成功播报及失败说明。
- StatisticCard 使用 16px 桌面留白，与 ChartCard 的 12px 圆角及内容边距对齐；说明、单位与口径采用 secondary 文字。原始数据展开后进入有边界的局部滚动区域，键盘焦点可见。数据表不将零视为空，不修改分类色、系列顺序、单位、聚合或比较基准。
- 统计示例的时间范围、刷新与空结果入口在读取时保留焦点，并阻止重复读取。失败保留原成功快照与已展开数据表；重试移除当前入口时，仅在入口原本拥有焦点且焦点已落到 body 时交给统计状态区。业务请求锁、原始请求参数和成功采纳仍由消费者维护。

第五轮继续使用现有 5177 的图片卡片、叠卡、Markdown、代码与统计页面，检查浅暗主题、390px、完整原文复制合同、图片预览回焦和统计恢复；保留实验室，不发版。截图过渡帧不作为稳定关闭／焦点恢复的验收证据，系统剪贴板字节与浏览器成功提示分别报告。


## Dock 实验

实验室 labs/dock 复用 Motion Primitives 的 MIT Dock 动效机制，保留固定上游和许可材料。窄屏、触屏及减少动态效果保持稳定按钮尺寸，原生按钮承担选择和键盘激活；方向键只移动焦点、不代替选择。实验限定在页面局部，不替换全局导航，不加入正式导出；主题沿用现有 Provider，业务导航由未来消费者显式接入。


## Dock 正式组件接入（0.2.12）

Dock实验经审核后进入独立/dock源码入口，motion保持optional peer，不进入根JS依赖图。/dock.css只包含该组件作用域样式，也并入styles.css；无需强制新增Provider。正式文档#/components/dock实际导入构建产物，提供受控选择/主题动作、全局禁用/减少动效与原生链接示例，实验室改为复用同一实现，原实验源码和审核记录保留。按钮与链接保留各自原生激活语义；activeId由消费者拥有，action不绘制虚假的选中态。自 0.2.12 通过版本包和 Registry 正式提供。


## 独立布局工作台

顶部“布局”和全局布局文档中的入口打开 workspace-layout.html，作为独立整页参考，不受文档栏与示例高度限制。Dock 项目工作台、生产多栏工作台、文档工作台和基础外壳复用现有公共组件；布局选择保留已访问实例、草稿与交互状态，未访问样板不提前渲染。整页体验可通过可见按钮或 Escape 退出，焦点返回原入口。样例只操作本地内存，不接入真实权限、请求或正式导出。

项目工作台顶栏保留项目与身份上下文，底部 Dock 使用五个原生导航入口；主内容与 Dock 占用独立布局空间，不覆盖表格末行或主要操作。Dock 外层需保留放大图标及完整提示的空间；不得通过缩短高度裁切标签，窄屏采用固定尺寸。

选择器下拉选项只用右侧对号表示已选，不叠加选中底色、描边或阴影。灰色底只表示鼠标悬停或键盘定位，移开后恢复同一浮层表面；这与导航树持续选中的浮起白面分开。

## Dock 工作台模板

使用 `WorkspaceLayout variant="dock"`：侧栏贯穿顶栏至 Dock 底部，Dock 仅对齐主工作区。顶部工作区与底部 Dock 各占一行，标签和项目切换浮层向上展开，不由内容面板裁切。

工作台各功能页使用 `WorkbenchPage` 的 toolbar、navigation、footer 插槽；工具栏在卡片上方，页签与正文属于同一表面。默认16px边距和区块间距、12px圆角、共享表面与轻阴影，窄屏边距12px。普通卡片、文档使用 `contentPadding="normal" scroll="body"`；表格、编辑器使用 `contentPadding="none" scroll="managed"`，只保留一个滚动所有者。卡片内部仍复用现有展示组件，不重复绘制整页外框。

通过 `--ls-workbench-gutter`、`--ls-workbench-gap`、`--ls-workbench-radius`、`--ls-workbench-body-padding`、`--ls-workbench-dock-height`、`--ls-workbench-dock-width` 和表面 tokens 在模板根统一配置，不在每个业务页覆盖边框和阴影。页面不会从模板获得路由、权限、持久化或业务请求。实验室保持独立，模板随 0.2.12 发布，来源许可未确认的实验仅留本地。
